# Repo workflow

This is a personal GitHub Pages portfolio site (solo-owned, no collaborators/PR review process). Default workflow for Claude Code sessions in this repo:

- Commit and push directly to `main`. Do not create feature branches or pull requests for routine updates (publications, content edits, styling) unless the user explicitly asks for a PR or a branch.
- If a session was started on an auto-generated feature branch, merge it into `main` and push `main` directly rather than leaving work stranded on the branch.
